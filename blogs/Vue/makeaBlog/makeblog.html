适用vue3的vuepress + vuepress-theme-reco的博客搭建教程

收收味2025-3-14Vue/makeaBlog博客vuepressvuepress-reco

记录我搭建博客以及自定义过程

nodejs版本：v22.14.0

npm：11.2.0

起步

创建空文件夹VuepressBlog

初始化项目

pnpm init

修改package.json的script

"scripts": {    
"docs:dev": "vuepress dev docs",
"docs:build": "vuepress build docs"
},

在package.js的 "devDependencies" 添加

"vue": "^3.5.0",

安装vuepress和vuepress-theme-reco

cd VuepressBlog
pnpm i vuepress@next -D
pnpm i vuepress-theme-reco@next @vuepress/bundler-vite@next -D

创建目录

  1. 创建目录docs，放置配置文件以及blog
  2. dcos下创建目录.vuepress放置配置文件
  3. .vuepress下创建文件config.ts这是最重要的文件，vuepress的所有相关配置都在此处
  4. 根目录下创建README.md,这是博客简介

创建完成后，你项目的目录结构应该是这样的：

├─ docs
│  ├─ .vuepress
│  │  └─ config.ts
│  └─ README.md
└─ package.json

博客搭建

设置主题

import { defineUserConfig } from 'vuepress'
import { recoTheme } from 'vuepress-theme-reco'

export default defineUserConfig ({
    theme: recoTheme({//这里是主题设置，填写关于vuepress-reco的配置
      
    }),
    lang: 'zh-CN',//网站的默认语言
    title: 'Ciallo~',//网站的标题
    description: '我的第一个博客',//网站的描述
})

设置导航栏内容

在recoTheme传递的对象中添加属性，navbar

navbar: [
      {
        text: '首页',
        link: '/',
      },
      {
        text: '收收味的博客',
        children: [
            {
                text: 'github',
                link: "https://github.com/ShiQi87"
            }
        ]
      }
    ]

到当前这步，网站就已经初具雏形了

markdown文件规划

由于使用了vuepress-theme-reco，它支持自动解析blogs文件夹下的文件并自动生成frontmatter的category

什么是frontmatter可以看这reco官方文档open in new window

在docs文件夹下新建文件夹blogs，存放markdown，一个分类的markdown放在同一文件夹下

/
└─ .vuepress
└─ blogs
  └─ 分类1
    └─ 博客1.md
  └─ 分类2
    └─ 博客2.md

然后在config.ts配置markdown（recoTheme中）

theme: recoTheme({//这里是主题配置，填写关于vuepress-reco的配置

        ···
        //如果文档放在这个文件夹下，务必要这样设置，因为这项配置与很多解析功能强相关。
        docsDir: '/docs',
        // 自动设置分类
        autoSetBlogCategories: true,
        ···

      })

markdown的显示

到这里有人会问，我往目录里放了markdown，但是博客首页根本没有显示啊

那是因为我们没有在README.md中添加内容

vuepress增加的frontmatter解析是markdown原本所没有的，首页的frontmatter也有专属的配置项，可以查看官网了解

我们在README.md中添加

---
home: true //是否首页
modules: 
    - BannerBrand
    - Blog
    - MdContent
    - Footer
---

参考open in new window (要魔法)

到这博客已经算是搭建完成，更多的自定义选项可以自己去官方的社区阅读文档

上线

我们使用GitHub提供的gh-pages部署静态页面到github上

创建仓库

以任意名字创建一个新的仓库，在config.ts中添加

export default defineUserConfig ({

    ···
    base: '/你的仓库名/',
    ···

    })

在根目录下创建新文件deploy.sh方便我们以后一键提交到GitHub

#!/usr/bin/env sh

# 确保脚本抛出遇到的错误
set -e

# 生成静态文件
pnpm run docs:build

# 进入生成的文件夹
cd docs/.vuepress/dist

git init
git add -A
git commit -m 'deploy'

# 如果发布到 https://<USERNAME>.github.io/<REPO>
git push -f git@github.com:XXX/XXX.git master:gh-pages

cd -

gitbash运行即可

其实用的方法有点麻烦了，直接用reco提供的模板修改一下也能用的
